# yomogyst 冷えタイプ診断

よもぎ蒸しサロン **yomogyst** の「冷えタイプ診断」。
8問であなたの冷えタイプ（末端／内臓／下半身／全身）を診断し、タイプ別のおすすめと予約導線（HotPepper Beauty）につなぐ、静的1ページのSPAです。

## 特徴
- 入口 → 8問 → 年代・性別 → 結果（御札風カード＋キャラクター）→ 予約 の流れ
- 冷えの4タイプ × 時間帯サブラベル
- 外部ライブラリ不使用・バニラJS・自己完結の1ファイル
- モバイルファースト

## 構成
- `index.html` — 本体（HTML / CSS / JS をインラインで内包）
- `img/` — 4タイプのキャラクター画像（透過PNG）

## デプロイ
ビルド不要の静的サイトです。Cloudflare Pages などにこのリポジトリを接続すれば、そのまま配信できます。

## 注記
本診断は生活習慣のセルフチェックであり、医学的な診断や体質・疾患の判定を行うものではありません。
